# Problem 3.5: Resource accounting

本文对应作业 PDF 第 27–28 页的 Problem (transformer_accounting)。计算对象是本作业实现的无偏置、使用 SwiGLU 和 RoPE 的 Transformer LM。

## 1. 符号、假设与通用表达式

### 1.1 符号

| 符号 | 含义 |
| --- | --- |
| $B$ | 批大小，即一次前向传播中的序列数 |
| $V$ | 词表大小 vocab_size |
| $T$ | 实际输入序列长度；本题数值计算中等于 context_length |
| $L$ | Transformer block 数量 num_layers |
| $d$ | 模型维度 d_model |
| $h$ | 注意力头数 num_heads |
| $f$ | 前馈层中间维度 d_ff |
| $d_h=d/h$ | 每个注意力头的 query、key 和 value 维度 |


### 1.2 参数量通式

单个 Transformer block 的参数组成如下：

| 组件 | 参数量 |
| --- | ---: |
| Query、Key、Value 投影 | $3d^2$ |
| 注意力输出投影 | $d^2$ |
| SwiGLU 的 $W_1,W_2,W_3$ | $3df$ |
| 两个 RMSNorm | $2d$ |
| 单个 block 合计 | $4d^2+3df+2d$ |

完整 Transformer LM 还包含 token embedding、最终 RMSNorm 和 LM head，因此总可训练参数量为

$$
\boxed{
P
=Vd+L(4d^2+3df+2d)+d+Vd
=2Vd+L(4d^2+3df+2d)+d
}.
$$

float32 参数本身所需内存为

$$
\boxed{M_{\mathrm{params}}=4P\ \text{bytes}}.
$$


### 1.3 前向传播矩阵乘 FLOPs 通式

对输入 $X\in\mathbb{R}^{B\times T\times d}$，将计算量相同的矩阵乘合并：

| 矩阵乘法 | 次数 | FLOPs |
| --- | ---: | ---: |
| $Q,K,V$ 投影 | 每个 block 3 次 | $3\times2BTd^2=6BTd^2$ |
| $QK^\top$ 与注意力权重乘 $V$ | 每个 block 各 1 次 | $2\times2BT^2d=4BT^2d$ |
| 注意力输出投影 | 每个 block 1 次 | $2BTd^2$ |
| SwiGLU 的 $W_1,W_2,W_3$ | 每个 block 3 次 | $3\times2BTdf=6BTdf$ |
| LM head | 整个模型 1 次 | $2BTdV$ |

为了后续比较，将 FLOPs 分为四组：

$$
\begin{aligned}
C_{\mathrm{attn\_proj}} &= 8BLTd^2,\\
C_{\mathrm{attn\_mix}}  &= 4BLT^2d,\\
C_{\mathrm{ffn}}         &= 6BLTdf,\\
C_{\mathrm{lm\_head}}    &= 2BTdV.
\end{aligned}
$$

因此总矩阵乘 FLOPs 为

$$
\boxed{
C_{\mathrm{total}}
=BL(8Td^2+4T^2d+6Tdf)+2BTdV
}.
$$

其中注意力内部的 $QK^\top$ 和注意力权重乘 value 都包含 $h$ 个 head，但代入 $d_h=d/h$ 后，$h$ 会约掉。

## 2. 作业问题逐项回答

### (a) GPT-2 XL 参数量与加载内存

配置为

$$
V=50{,}257,\quad T=1{,}024,\quad L=48,\quad
d=1{,}600,\quad h=25,\quad f=4{,}288.
$$

参数量分解如下：

| 组件 | 参数量 |
| --- | ---: |
| Token embedding：$Vd$ | 80,411,200 |
| 48 层注意力权重：$L\cdot4d^2$ | 491,520,000 |
| 48 层 SwiGLU 权重：$L\cdot3df$ | 987,955,200 |
| 所有 block RMSNorm 与最终 RMSNorm：$2Ld+d$ | 155,200 |
| LM head：$Vd$ | 80,411,200 |
| **总计** | **1,640,452,800** |

答案：该模型共有 **1,640,452,800 个可训练参数，约 1.640B**。只加载 float32 参数需要

$$
1{,}640{,}452{,}800\times4
=6{,}561{,}811{,}200\ \text{bytes}
\approx6.562\ \text{GB}
\approx6.111\ \text{GiB}.
$$

### (b) GPT-2 XL 一次前向传播的矩阵乘与总 FLOPs

这里取 $B=1,T=1{,}024$。下表中的数值已经包含全部 48 个 Transformer block；LM head 只计算一次。

| 矩阵乘法 | FLOPs | $10^{12}$ FLOPs |
| --- | ---: | ---: |
| $Q,K,V$ 投影（3 倍） | 754,974,720,000 | 0.754975 |
| $QK^\top$ 与注意力权重乘 $V$（2 倍） | 322,122,547,200 | 0.322123 |
| 注意力输出投影 | 251,658,240,000 | 0.251658 |
| SwiGLU 的 $W_1,W_2,W_3$（3 倍） | 2,023,332,249,600 | 2.023332 |
| LM head | 164,682,137,600 | 0.164682 |
| **总计** | **3,516,769,894,400** | **3.516770** |

答案：处理一个长度为 1,024 的序列时，GPT-2 XL 形状的作业模型需要

$$
\boxed{3{,}516{,}769{,}894{,}400\ \text{FLOPs}
\approx3.517\times10^{12}\ \text{FLOPs}}.
$$

### (c) 哪些部分使用最多 FLOPs

SwiGLU 前馈网络占总矩阵乘 FLOPs 的 **57.53%**，是开销最大的部分；注意力线性投影占 **28.62%**，$QK^\top$ 与注意力权重乘 value 合计占 **9.16%**，LM head 占 **4.68%**。因此在 $T=1{,}024$ 的 GPT-2 XL 配置中，主要计算量来自前馈网络，而不是二次复杂度的注意力混合。

### (d) GPT-2 Small、Medium、Large 的 FLOPs 占比

保持 $V=50{,}257,T=1{,}024,B=1$。按照作业架构，$f$ 取最接近 $\frac{8}{3}d$ 的 64 的倍数：

| 模型 | $L$ | $d$ | $h$ | $f$ |
| --- | ---: | ---: | ---: | ---: |
| GPT-2 Small | 12 | 768 | 12 | 2,048 |
| GPT-2 Medium | 24 | 1,024 | 16 | 2,752 |
| GPT-2 Large | 36 | 1,280 | 20 | 3,392 |
| GPT-2 XL | 48 | 1,600 | 25 | 4,288 |

各组件数值以 $10^{12}$ FLOPs 表示，括号内是其占总 FLOPs 的比例：

| 模型 | 注意力投影 | 注意力混合 | SwiGLU FFN | LM head | 总 FLOPs |
| --- | ---: | ---: | ---: | ---: | ---: |
| Small | 0.057982（19.88%） | 0.038655（13.25%） | 0.115964（39.76%） | 0.079047（27.10%） | 0.291648 |
| Medium | 0.206158（24.83%） | 0.103079（12.42%） | 0.415538（50.05%） | 0.105397（12.70%） | 0.830172 |
| Large | 0.483184（27.32%） | 0.193274（10.93%） | 0.960328（54.30%） | 0.131746（7.45%） | 1.768531 |
| XL | 1.006633（28.62%） | 0.322123（9.16%） | 2.023332（57.53%） | 0.164682（4.68%） | 3.516770 |

答案：在词表和上下文长度不变时，模型越大，SwiGLU 和注意力投影所占比例越高；SwiGLU 从 **39.76%** 上升到 **57.53%**。LM head 不随层数 $L$ 增长，其占比从 **27.10%** 降到 **4.68%**；注意力混合只对宽度呈线性增长，而投影和 FFN 对宽度近似呈二次增长，因此注意力混合占比也从 **13.25%** 降到 **9.16%**。

### (e) GPT-2 XL 的上下文长度增至 16,384

将 $T$ 从 1,024 增大到 16,384，即增大 16 倍。注意力投影、FFN 和 LM head 都与 $T$ 成正比，因此增大 16 倍；注意力混合与 $T^2$ 成正比，因此增大 $16^2=256$ 倍。

| 组件 | $T=1{,}024$ | 占比 | $T=16{,}384$ | 占比 |
| --- | ---: | ---: | ---: | ---: |
| 注意力投影 | 1.006633 | 28.62% | 16.106127 | 12.06% |
| 注意力混合 | 0.322123 | 9.16% | 82.463372 | 61.73% |
| SwiGLU FFN | 2.023332 | 57.53% | 32.373316 | 24.24% |
| LM head | 0.164682 | 4.68% | 2.634914 | 1.97% |
| **总计** | **3.516770** | **100%** | **133.577730** | **100%** |

表中 FLOPs 数值的单位均为 $10^{12}$。总矩阵乘 FLOPs 从约 $3.517\times10^{12}$ 增长到 $133.578\times10^{12}$，即增大约

$$
\frac{133.5777296384}{3.5167698944}
\approx\boxed{37.98\text{ 倍}}.
$$

答案：上下文长度增至 16,384 后，一次前向传播约需 **$1.336\times10^{14}$ FLOPs**，约为原来的 **37.98 倍**。计算瓶颈从 SwiGLU 转为注意力混合，后者占比由 **9.16%** 上升到 **61.73%**，体现了长上下文下注意力 $O(T^2)$ 成本的主导作用。
